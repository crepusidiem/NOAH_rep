Checked: 2026-10-19, America/New_York. Source baseline: `1d21fd6f85d4fabbf6cdf0022e865db82cc52dc7`, with pre-existing uncommitted training/probing work preserved. This document maps current code to the paper; it is not evidence of completed real-data retraining.

## Authoritative architectural specification

The existing [reproduction specification](REPRODUCTION_SPEC.md) already inventories the paper's architecture, data interface, objectives, training constants and evaluation protocols. Its [traceability matrix](PAPER_TRACEABILITY.md) supplies exact paper locations; [assumptions](ASSUMPTIONS.md) separates missing details. These documents substantially agree with the local paper. They do not establish that the implementation follows them.

Primary source: [NOAH.pdf](../paper/NOAH.pdf), arXiv:2609.09140v1, 50 pages, SHA-256 `0f3a7bb049d6f7eb6cdf61c2aa9692d0695037851f95b73711a26ed803576730`, rechecked locally. Methods pp.15–21 and Table16 p.50 were compared directly with extracted PDF text; Fig.1f was visually inspected and supplies the linear additive input graph and the age/directional-gap/position time-feature interface. E01–E16 remain local equation locators. No author implementation was inspected.

EXPLICIT denotes paper text/figure/table; DERIVED denotes a mathematical consequence; ASSUMED denotes a candidate filling an omitted detail; DEVIATION denotes a changed paper requirement. A passing synthetic test verifies a mechanism, not its encoder/data provenance or scientific equivalence.
